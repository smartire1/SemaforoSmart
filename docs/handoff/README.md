# Handoff e continuita' del progetto

Contesto condiviso per continuare SemaforoSmart su Windows o macOS senza perdere
decisioni, risultati e metodo di lavoro.

## Contenuto

- `CONTESTO_CODEX.md`: contesto principale da fornire a una nuova chat;
- `SYNC_PC_MAC.md`: procedura provvisoria di sincronizzazione manuale.

Comandi operativi: `../guides/COMANDI_OPERATIVI.md`. Prompt iniziale, audit del
primo trasferimento e snapshot dell'ambiente sono conservati in `../archive/`.

## Uso rapido

1. Sincronizzare i file necessari seguendo `SYNC_PC_MAC.md`.
2. Aprire la root in Codex.
3. Fornire `CONTESTO_CODEX.md` alla nuova chat.
4. Verificare lo stato corrente in `../project/STATO_PROGETTO.md`.

Il contesto deve essere aggiornato quando cambia la baseline o si conclude un
ramo sperimentale rilevante.

Stato corrente: baseline v1.3; primo ramo Copy-Paste DAY concluso e non
promosso. Prima del trasferimento consultare anche
`../../data/raw/v1.3_cp/README.md`.
